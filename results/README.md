# Results

Generated outputs and evaluation results should be written under this directory and are ignored by Git.

Use this convention:

```text
results/evaluation/VGGSound-Sparse/quantitative/YYYY-MM-DD_model-dataset-setting/
results/evaluation/VGGSound-Sparse/qualitative/YYYY-MM-DD_model-dataset-setting/
```

Do not commit generated samples, metric tables, plots, or intermediate outputs.
