# Configs

Place CounterFlow-level configuration files here. Backend-specific configs should
remain in their external repositories unless they are project-owned overrides.

Research configs are grouped by axis:

```text
configs/research_axes/latent_update_method/
configs/research_axes/target_prompt_generation/
configs/research_axes/evaluation_metrics/
```

Keep generated outputs, checkpoints, feature caches, and large tensors out of
this directory.
